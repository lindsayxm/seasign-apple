# Seasign project setup: add iOS MCP servers and close the gaps before development

## Context

`/Users/li/seasign/seasign-apple` holds the agent scaffolding for Seasign (native iOS app + Cloudflare API), but it was carried over from an earlier SvelteKit stack and is incomplete:

- `.mcp.json` still lists the Svelte server and has nothing for Swift, Xcode or Apple docs.
- `.claude/settings.json` runs four hook scripts that do not exist (`hooks/` is empty), so every session start and tool call hits a missing file.
- `AGENTS.md` names three skills (`session-wrap-up`, `task-workflow`, `scaffold-app`) and three `memory/` items that do not exist.
- There is no git repository, although the rules require commits with task IDs.
- `xcodegen` is not installed; `.gitignore` and the permissions have no Xcode or Apple-signing entries.

Decisions from the user: use **XcodeBuildMCP** (Apple's `xcrun mcpbridge` needs Xcode 26.3+, this Mac has 16.2), add **sosumi.ai** for Apple docs, **write the hooks and skills new**, git root is **`seasign-apple/`**. Tasks stay on the local `./tasks/task` board; no GitHub.

All paths below are relative to `seasign-apple/`.

## Changes

### 1. `.mcp.json`
- Remove `svelte`.
- Add `XcodeBuildMCP` (stdio): `npx -y xcodebuildmcp@latest mcp`, with env `XCODEBUILDMCP_SENTRY_DISABLED=true` (telemetry off). Before writing, run `npx -y xcodebuildmcp@latest --help` to confirm the `mcp` subcommand and the env var name for the current release.
- Add `sosumi` (http): `https://sosumi.ai/mcp`.
- Keep `cloudflare-api`, `cloudflare-docs`, `better-auth`.

### 2. `.claude/settings.json`
- `enabledMcpjsonServers`: the five servers, so they load without a prompt.
- `allow`: add `Bash(xcodegen generate*)`, `Bash(xcodebuild *)`, `Bash(xcrun simctl *)`, `mcp__XcodeBuildMCP`, `mcp__sosumi`, `mcp__cloudflare-docs`, `mcp__better-auth`. (`cloudflare-api` stays unlisted so account changes prompt.)
- `ask`: add `Bash(fastlane *)`, `Bash(xcrun altool *)`, `Bash(xcrun devicectl *)`, `Bash(xcrun notarytool *)`.
- `deny`: add Read/Edit for `**/*.p8`, `**/*.p12`, `**/*.cer`, `**/*.mobileprovision`; move `git push` from `ask` to `deny` so it matches the "Never" rule in AGENTS.md.

### 3. `hooks/` (four new zero-dependency Node scripts, matching the commands already in settings.json)
| file | event | behaviour |
|---|---|---|
| `session-start.mjs` | SessionStart | prints the last `PROJECT-STATUS.md` entry and `./tasks/task list --open` as context |
| `guard-secret-files.mjs` | PreToolUse Read/Edit/Write/Bash | exit 2 when the path or shell command names `.env*` (except `.env.example`), `.dev.vars*`, `*.toml`, `.wrangler/`, or signing material (`*.p8`, `*.p12`, `*.cer`, `*.mobileprovision`); also blocks edits to `*.xcodeproj/**` |
| `guard-task-files.mjs` | PreToolUse Edit/Write/Bash | blocks edits to `tasks/NNNN-*.md`; blocks shell writes to task files or `PROJECT-STATUS.md`; allows Edit on `PROJECT-STATUS.md` only when it appends |
| `require-task-id.mjs` | PreToolUse Bash | blocks `git commit` whose message lacks `[#N]` or `[no-task]` |

Each reads the hook JSON on stdin, and fails open (exit 0) on unparseable input so a hook bug cannot lock the session.
