# v4 — cartography

Today as an engraved plate, after `design-ideas/ref-img/v4-cartography/`: off-white paper with dark ink by day, charcoal paper with chalk-white ink at night. Look only; no app code.

- Weather is not drawn. It is a sign beside the temperature (clear, clouds, rain, snow, clear night), drawn in the manner of the app's settings, list and saved signs. The page shows the full set beside the phone.
- `index.html` is the mockup; it moves only slightly (rings spreading from the sun, orbits turning round the moon). Open it in a browser (`open design-ideas/v4-cartography/index.html`) and pick a state, or step through with the arrow keys.
- `01-sunrise.png` … `12-moon-set.png` are stills of the same twelve states as `design-ideas/v1-original/`, at iPhone size.
- Type is Baskerville and Snell Roundhand, which come with macOS and iOS; no font files are needed.
