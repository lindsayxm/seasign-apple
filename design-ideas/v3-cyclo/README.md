# v3 — cyclo

Today restyled after `design-ideas/ref-img/v3-cyclo/night.png`: a dark sky with fine drawn geometry and a small point of light for the sun or moon. Look only; no app code.

- `index.html` is the animated mockup. Open it in a browser (`open design-ideas/v3-cyclo/index.html`) and pick a state, or step through with the arrow keys.
- `01-sunrise.png` … `12-moon-set.png` are stills of the same twelve states as `design-ideas/v1-original/`, at iPhone size.
- `fonts/` holds a copy of the app's Jost font so the page works offline.
