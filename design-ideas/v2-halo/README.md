# v2 — halo

Today restyled after `design-ideas/ref-img/v2-halo/`: the sun and moon are rings of light, with glow, lens flares and a shimmering reflection. Look only; no app code.

- `index.html` is the animated mockup. Open it in a browser (`open design-ideas/v2-halo/index.html`) and pick a state, or step through with the arrow keys.
- `01-sunrise.png` … `12-moon-set.png` are stills of the same twelve states as `design-ideas/v1-original/`, at iPhone size.
- `fonts/` holds a copy of the app's Jost font so the page works offline.
