# v1 — original

The app as it is built today.

- `01-sunrise.png` … `12-moon-set.png` are screenshots of the real app in the iPhone 17 Simulator, with sample events and headlines.
- `index.html` is the same look redrawn for the browser, so it can be compared with the other versions the same way. Open it (`open design-ideas/v1-original/index.html`) and pick a state, or step through with the arrow keys. It uses the app's own colours, icon shapes, cloud shapes and sizes, copied from `ios/Seasign`; if the app changes, this page does not follow.
- `fonts/` holds copies of the app's fonts (Jost, PT Sans Narrow) with their licences.
