## Goal

Plan plans/2026-11-22-day-calendar-and-voice.md, task 3. Create one event in a Google calendar the user owns. Header X-Google-Token, never stored or logged. 'with Rahaf' is title text only: no attendees, no invitations, no location, no description, no recurrence.

## Acceptance criteria

- [x] Look up first and cite in the log: Google's events.insert reference (body, sendUpdates default, client-supplied id rules: allowed characters and length, what a duplicate id answers), and the exact 403 bodies for a token without a write scope versus a calendar the user cannot write to
- [x] Route under /v1/google (google rate-limit group, no-store): body calendar id, title (trimmed, 1 to 200 characters), either start and end instants with an IANA time zone or an all-day date, and a client-made event id; validation with fixed 400s; end after start; at most 24 hours long for timed events
- [x] Calls events.insert through postGoogleJson with fields limited to what the app shows; returns the created event in the existing UpcomingEvent shape; a retry with the same id that Google reports as a duplicate is answered as success (the event exists), not as an error
- [x] Errors: 401 google_auth, 403 insufficient_scope (token lacks write access), 403 forbidden (calendar not writable), 404 not_found, 429 rate_limited, 502 fetch_failed, timeout; fixed bodies; the token, title and times never logged
- [x] Tests with mocked Google that record the request body: happy path timed and all-day, each error, duplicate id, validation cases, nothing secret or private in logs; npm test and tsc pass; npm run openapi regenerated; the iOS app still builds

## What's been tried

- Spec gotchas with @hono/zod-openapi + zod 4: (1) a .regex() with the u flag (/^[^\p{Cc}]*$/u) is written into the spec pattern with its flag ('^[^\p{Cc}]*$/u'), a broken pattern; use a pattern without flags (now /^[^\x00-\x1f\x7f-\x9f]*$/). (2) .openapi({ description }) on an optional schema property that is a registered component (CalendarEventSchema) turns its $ref into allOf, which the Swift generator wraps (value1); leave the property bare and put the text on the parent schema. (3) isTimeZone alone lets +05:00, EST, lower-case names through (Intl accepts them); for a zone forwarded to Google use isIanaZone from routes/discover.ts.
