## Goal

Plan plans/2026-11-22-day-calendar-and-voice.md, task 2. The day screen needs every event of one day, ended ones included; both routes return only events that have not ended. The default-calendar picker needs to know which Google calendars are writable.

## Acceptance criteria

- [x] POST /v1/calendar/events and POST /v1/google/events take an optional day (YYYY-MM-DD, validated, used with the existing timezone); with it they return the events that overlap that day in that zone, ended ones included, all-day events placed as now, sorted as now, same cap; without it behaviour is byte-for-byte as before (existing tests untouched and passing)
- [x] Pasted links: first establish what the KV entry holds (CachedCalendar, parseCalendar's window); if it does not cover earlier today, widen what is parsed and cached so a day request is answered from the cache like any other; fresh still works; memory caps unchanged or re-argued in the log. Google: timeMin at the start of the day; the day may be today or within the existing 7-day window (reject others with the fixed 400)
- [x] GET /v1/google/calendars returns Google's accessRole per calendar (owner, writer, reader, freeBusyReader) from calendarList, nothing else new
- [x] Tests for each of the above including zone edges (an event ending at local midnight, an all-day event, a day in a zone far from UTC); npm test and npx tsc --noEmit pass; npm run openapi regenerated; the iOS app still builds

## What's been tried

- Widening KEEP_BEFORE itself from 1 to 2 days (parseCalendar's only window): correct for the route, but 45 existing tests in calendar-parse.test.ts and calendar-smuggling.test.ts pin parseCalendar's default one-day window (a reference iterator helper, a fixed expected list, step counts). The three 'hostile and broken files' failures only showed one more day of occurrences (2026-11-15 added, 40x10 instead of 40x9 occurrences); partial and the work budget behaved the same. Replaced by an optional keepBefore argument, default one day, that the route passes as two days.
