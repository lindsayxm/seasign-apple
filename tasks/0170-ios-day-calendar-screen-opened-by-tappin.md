## Goal

Plan plans/2026-11-22-day-calendar-and-voice.md, task 5. Full-screen list of all of today's events from Google and pasted links, ended ones included, with a mic button top right and a + button below it (wired in later tasks).

## Acceptance criteria

- [x] The events box on Today is a button (whole box, 44 pt minimum, VoiceOver label); tappable also when there are no events; the pull gesture and the zip prompt still work; it opens Destination.day as a fullScreenCover like History
- [x] DayModel: its own snapshot of today's events from both sources through the day parameter, merged and ordered by start (all-day first), in the events zone (EventZone.resolve); refreshes on open, on return to the foreground and on its own timer while open (Google 5 s like Today's poll rules, pasted links 5 minutes); per-source failures keep what is shown; Today's next-three logic and models untouched
- [x] DayView in the app's style (SheetScaffold or the History header, CloseMark, EventLabel times, ended events dimmed, an empty state); mic and + buttons top right with 44 pt targets, in the icon style of the other screens; until tasks 171 and 172 they open a short 'coming soon' note or are hidden behind a flag, the implementer says which
- [x] Tests for DayModel (merge order, ended events kept, zone, failure handling, refresh gating) and that Today's labels are unchanged. Suite passes on both runtimes; screenshots on the iPhone 17 with -debugGoogle of Today and the day screen
